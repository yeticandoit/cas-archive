# CAS Archive

A fan-made Cigarettes After Sex discography / listening interface.

## Pages
- `index.html` — home
- `music.html` — searchable discography + local audio player
- `artist.html` — artist information
- `developer.html` — developer page

## Playback
The site intentionally does not ship copyrighted recordings. On `Music`, use the `＋ Audio` control to load your own licensed/local audio files. Name files after the track title, e.g. `Apocalypse.mp3`, and the player will map them to the catalog.

## Lyrics
Full lyrics are not bundled into the project. Each release points to an official CAS page where appropriate.

## Run
Open `index.html` in a modern browser. For best results, serve the folder through a simple local web server.

## Customize
Edit `data.js` to add releases, official links, artwork references, or future catalog updates. Replace the placeholder covers with licensed artwork if you have permission.
